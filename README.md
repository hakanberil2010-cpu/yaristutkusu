# YarışTutkusu — Vercel sürümü

GitHub'a şu öğeleri yükleyin:
- public/
- api/
- package.json
- vercel.json
- supabase-schema.sql
- server.js

Canlı üyelik sistemi için Supabase gerekir. Vercel'de şu environment variables oluşturulmalıdır:
SUPABASE_URL
SUPABASE_SERVICE_ROLE_KEY
JWT_SECRET

SERVICE_ROLE_KEY'i GitHub'a veya frontend'e koymayın.
